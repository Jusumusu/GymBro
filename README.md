# Gym Bro v29 — interface and reliability overhaul

- Upload `index.html`, `sw.js`, `manifest.webmanifest`, and the `icons/` folder to the **root** of your current GitHub Pages repository.
- Keep the same URL to preserve locally saved workouts, plans, measurements, goals, and progress photos.
- Export a **complete backup including photos** from Settings before updating.
- This version preserves existing storage keys and backup JSON formats.
- It introduces a temporary memory-only mode for restrictive HTML previews: controls work, but closing the preview loses those temporary changes.
- On GitHub Pages (HTTPS), the app uses persistent browser storage normally. Clear Safari website data only after backing up.
- Automatic progression is a suggestion based on your actual logged sets and selected rep ranges, not a guarantee of improved performance or muscle growth.
