# Gym Bro v25 — Settings and bottom navigation fix

- Settings opens as its own full-screen panel and the bottom navigation hides while Settings is open.
- The Metric / Imperial buttons switch units immediately without reloading the app.
- Existing kg/cm records, custom plans, sessions, body weight, and wellness data keep their storage formats.
