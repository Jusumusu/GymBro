# Gym Bro v32 — Adaptive Mobile Edition

Fully responsive layouts for narrow/wide phones, tablets, landscape, safe areas, accessible text and mobile keyboards. Same original workout, plan, data storage and backup formats.

Deployment: upload index.html, manifest.webmanifest, sw.js and the icons/ directory to your existing GitHub Pages repository root. Export a complete backup from Settings before upgrading.

Settings can scroll on short/landscape or enlarged-text screens so every control stays reachable. Desktop and browser tests are not equivalent to testing every physical phone.
